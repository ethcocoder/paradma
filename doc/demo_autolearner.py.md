# paradma/demo_autolearner.py

## Overview
A comprehensive, multi-phase demonstration of the Paradma project's "From Dependency to Independence" journey.

## Phases
1. **Student Phase**: The system admits it doesn't know how to add, so it asks NumPy to do the work, logging every interaction.
2. **Learning Phase**: The system analyzes the logs to extract algorithms for simple math.
3. **Verification Phase**: The system proves it can now solve new problems without help.
4. **Advanced Phase**: The system scales up to learn complex operations like Matrix Multiplication and Square Roots.
5. **Autonomy Phase**: A final report showing that the AI is now running on its own self-written code.

## Purpose
This script is the primary "Showcase" for the Paradma substrate. It visually demonstrates the transition from a wrapper library to a self-sufficient mathematical engine.
